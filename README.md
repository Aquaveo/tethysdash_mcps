# tethysdash MCP server

Standalone MCP (Model Context Protocol) server providing the tethysdash dashboard-creation tool surface (25 `@mcp.tool` definitions + 25 `@mcp.prompt` slash-command templates) as a containerizable Python package.

This is a parallel artifact extracted from `tethysapp-tethys_dash/tethysapp/tethysdash/mcp/`. The embedded MCP server inside tethysdash remains the developer-local default and the canonical home until deploy work resumes.
